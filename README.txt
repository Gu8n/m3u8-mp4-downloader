M3U8 a MP4 HD (starter)

Archivos: server.py, index.html, requirements.txt.
Requiere Python y FFmpeg instalado en el servidor.
Instalar dependencias: pip install -r requirements.txt
Ejecutar: python server.py

El servicio solo debe usarse con streams que tengas permiso de descargar.
No puede descifrar DRM. Antes de publicar, añade controles estrictos contra SSRF,
restricciones de dominios, autenticación y límites de uso. Este proyecto inicial
no está listo para alojar públicamente como descargador abierto.
